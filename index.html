BEFORE YOU BEGIN

先备份，再重装

面板重装和 DD 写盘都可能清除磁盘数据。提前备份网站、数据库和配置文件，确认备份可用及恢复方式，并保存面板登录信息和当前连接信息。

02 / KIWIVM

在面板中
重装 Linux

以下是参考资料中的操作顺序。界面及可用系统可能变化，请以面板实际显示为准。

预备工作
备份数据 · 保存连接信息

  1. 进入 KiwiVM

    登录账号，在 Services → My Services 中找到对应 VPS，进入 KiwiVM Control Panel。

  2. 停止服务器

    在 Main Controls 查看状态；如果正在运行，选择 Stop 并等待完全关机。

  3. 选择系统

    进入 Install new OS，从面板实际列出的版本中选择。需要安装 Ubuntu 或 Debian 时，可先确认所需版本是否在列表内。

  4. 确认并重装

    仔细阅读数据清除提示，确认备份后勾选同意项，再点击 Reload。

  5. 保存新的连接信息

    安装完成后记录显示的密码，并在面板中核对 SSH 端口；使用新凭据连接服务器。

03 / ADVANCED PATH

DD：将镜像写入磁盘

DD 不是面板里选择发行版的另一种按钮，而是将系统镜像写入磁盘的进阶方式。操作会覆盖原有系统和数据，镜像来源与内容也需要自行审查。

01

准备环境

确认 VPS 使用 KVM，先安装可连接的 Linux 系统，并确保能够通过 SSH 登录。

02

核实镜像

选择可信来源的镜像，了解其写盘和启动要求。执行前确认目标磁盘与恢复方式。

03

安装后检查

用新系统的连接信息重新登录；如果镜像带有默认密码，应立即修改。

如需安装 Windows 或使用 ISO，请先确认当前面板是否提供相应功能，以及镜像和安装方式是否适用。本指南不提供 DD 脚本或镜像下载。

04 / AFTER INSTALLATION

重装后连不上？

先在 KiwiVM 面板核对 SSH 端口，再检查用户名、密码以及防火墙设置。不要直接假设端口仍是 22。

如果连接信息无误仍有网络问题，还需要单独排查线路和网络状态；重装系统不能替代网络排查。

06 / QUESTIONS

常见问题

操作前多确认一步，恢复时就少一份不确定。

重装之前需要备份什么？

备份需要保留的网站文件、数据库和配置，并确认备份可以恢复。重装可能清除原磁盘上的数据。

面板里没有想要的系统怎么办？

先查看当前可用的系统列表。对于有经验的用户，自定义镜像可能是另一条路径；如果考虑 ISO 安装，先确认面板是否提供该功能。

重装后 SSH 为什么连接失败？

先核对面板显示的端口、新密码和用户名，再检查防火墙及网络连接。

DD 镜像需要注意什么？

镜像可能包含不安全的配置或默认凭据。选择可信来源，了解镜像内容，并在安装后修改默认密码。
